Pipeline

  1. Submit → queued JSONL (not Lit_Review).
  2. Merge → approved rows into Virus.xlsx Lit_Review.
  3. Retrain / compare → candidate models in R vs baseline (metrics below).
  4. Promote → replace chlorine_tool/artifacts/rf_nonlinear.rds, restart.

Candidate vs baseline (in R; not on this site)

  • R², RMSE — holdout or CV predictions vs Constant.
  • OOB — ranger prediction.error / derived R².
  • k-fold CV R² — caret or manual folds.
  • LOO — small n only; costly for large forests.

Do not rely on training R² alone; use OOB and/or CV before adding complexity.
